# Sidharth Rai — Personal Portfolio Website

A responsive single-page personal portfolio created for **Web Design Assignment 1** using HTML, CSS and JavaScript.

## Project structure
```text
Personal_Portfolio_Assignment/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── profile-illustration.svg
```

## Run in VS Code
1. Extract the ZIP file.
2. Open the `Personal_Portfolio_Assignment` folder in VS Code.
3. Open `index.html`.
4. Right-click and choose **Open with Live Server** (if Live Server extension is installed), or double-click `index.html` to open it in a browser.

## Before submitting — personalize these details
- Replace the illustration in `assets/profile-illustration.svg` with your own photo if you want. Keep the filename `profile-illustration.svg`, or update the image path in `index.html`.
- In `index.html`, replace `your.email@example.com` with your real email address.
- In `script.js`, replace `your.email@example.com` in the `recipient` variable.
- Update LinkedIn and GitHub links with your actual profile URLs.
- Add real project demo/repository links if available. Project cards currently link to the Contact section rather than claiming a live demo exists.

## Assignment requirements covered
- Home, About Me, Skills, Projects and Contact sections
- Headings, paragraphs, hyperlinks, image, lists/navigation, skills table and contact form
- External CSS, selectors, colors, fonts, box model and Flexbox
- Responsive layout for desktop, tablet and mobile
- Hover effects, transitions and scroll reveal animation
- JavaScript mobile navigation and contact-form email-app handoff

## Contact form note
The form is a front-end demo. It opens the visitor's default email application using `mailto:`. It does not save messages to a database or send them through a server. For a production contact form, connect a backend or a form service.
